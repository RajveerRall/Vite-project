# YoRead Portable Desktop App

This is a portable version of YoRead that includes all necessary servers.

## Quick Start

1. Run launcher\start-app.bat to start the application
2. The servers will start automatically
3. Open your browser to the frontend URL

## Files

* launcher\ - Launcher scripts
* servers\ - Server executables
* frontend\ - Built frontend application

## Server Ports

* Frontend: http://localhost:8080
* Full Cast TTS: http://localhost:4001
* Video Generator: http://localhost:8000

## Requirements

* Windows 10 or later
* Python 3.8+ (for frontend server)
* FFmpeg (for video generation) - must be installed separately or bundled
